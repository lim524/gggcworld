# 지도 미리보기와 모험 첫 화면

- 홈 지도는 4명의 수호신과 군도를 보여주는 표시 전용 미리보기입니다. 지도 아래 시작 버튼과 안내 문구, 지도 클릭 모험 진입은 없습니다.
- 오른쪽 아래 수호신 캐릭터 → 메뉴의 모험 → `/adventure?faction=선택한신` 새 탭으로 진입합니다.
- 모험은 커뮤니티 레이아웃과 분리된 화면 전체 크기의 게임입니다. 브라우저 전체화면 API는 명시적인 전체화면 버튼 클릭으로만 사용하며 미지원 환경에서는 버튼을 숨깁니다. 모바일 세로·가로 및 동작 줄이기 설정을 지원합니다.
- 모험에 진입하면 로그인 계정의 초원으로 바로 입장합니다. 별도 타이틀·항구 인사는 거치지 않고 첫 방문 때 수호신의 조작 안내 이벤트를 지도 위에 표시합니다. 안내 중 이동은 멈추며, 이후 ‘조작 안내’에서 다시 열 수 있습니다. 이는 고정 안내이며 AI 생성 응답이 아닙니다.
- 기존 프롤로그·탐험 노트 저장 키는 삭제하지 않습니다. 현재 위치와 조작 안내 확인 기록은 별도의 계정별 기기 내 키에 저장합니다.
- 종전의 지도 목적지 선택·자동 이동·8개 장소 수집 화면은 모험 페이지에서 제거했습니다. 지도와 캐릭터 이미지는 기존 자산을 재사용합니다.
- 이후 방향: 운영자가 정하는 세계관·주요 사건 틀과 이용자가 BYOK로 연결하는 AI의 개별 이야기. 이번 버전은 설정에서 연결 준비 상태만 표시하며 API 키를 받거나 저장하거나 전송하지 않습니다. AI 호출·개별 스토리 생성은 아직 없습니다. 코드 타일을 사용하는 진영별 초원 이동은 별도 탐험 화면에 추가했습니다. [초원 탐험 안내](meadow-exploration.md)를 참고하세요.
- 홈 지도는 기존 8프레임 물결·분수·깃발 효과와 낮·밤·일시정지를 유지합니다. 로그인·게시판 API 및 DB 스키마는 변경하지 않습니다.

현재 이동 기능: 모험 페이지가 초원을 바로 열며 PC 방향키/WASD, 터치 기기의 스와이프·방향패드를 지원합니다. 방향패드는 데스크톱에서 숨깁니다. 모바일 가로·세로 배치와 안전 영역을 반영합니다.
