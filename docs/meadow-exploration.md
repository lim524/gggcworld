# 네 종류 타일 초원 탐험

첫 버전은 AI 이미지 생성 없이 Canvas로 잔디·흙(32×32), 나무(32×48), 돌(32×32)을 직접 그립니다. 나무와 돌은 바닥 위에 올리는 장애물이며, 나무는 한 칸을 점유하고 수관이 위로 겹쳐집니다. 기존 수호신 스프라이트를 캐릭터로 재사용합니다. 방향별 걷기 스프라이트는 아직 없고 기존 정면 애니메이션과 위치 보간으로 이동합니다.

## 진입과 조작

- 수호신 메뉴에서 모험을 새 탭으로 열면 로그인 계정의 초원으로 바로 진입합니다. 별도 타이틀과 항구 인사를 거치지 않습니다. 첫 진입 시 수호신의 조작 안내 이벤트를 지도 위에 표시합니다. 계정별 기기 내 안내 확인 기록을 보관하며 ‘조작 안내’에서 다시 열 수 있습니다.
- 탐험은 로그인과 진영 확정이 필요합니다. URL의 faction이나 요청 본문은 지역 권한으로 신뢰하지 않습니다.
- 로그인한 그록 계정은 녹스 캐릭터로 보랏빛 황혼 초원에 진입합니다. 다른 세 진영도 자기 초원을 사용합니다.
- PC 방향키/WASD, 모바일 스와이프 및 누르는 동안 연속 이동하는 방향패드를 지원합니다. 방향패드는 (hover:none) and (pointer:coarse)인 터치 기기에만 표시하고 데스크톱에서는 숨깁니다. 모바일 세로·가로 배치와 안전 영역을 반영하며 화면 회전 시 캔버스 크기를 다시 맞춥니다. 가로 방향 강제 고정은 하지 않습니다.
- 캐릭터 이동 시 카메라가 따라갑니다. 나무·돌 충돌, 설정창·탭 비활성화 시 입력 해제, 동작 줄이기 설정을 반영합니다.
- 조작 안내와 설정창이 열려 있는 동안 이동 입력을 막습니다. 위치는 계정별 로컬 저장 키 gggc-explorer-v1:<userId>에 보관합니다. 위치 서버 동기화나 다른 플레이어 표시는 아직 없습니다.

## 생성·공유

- 32×24 타일 구역입니다. 버전·진영·좌표 기반 시드로 바닥과 물체 배열을 생성하고, 진입점 네 곳과 안전한 중앙 출발점은 연결합니다.
- POST /api/world/chunks {x,y}: 세션의 진영에 해당하는 구역을 읽고, 없으면 서버가 생성해 D1에 확정합니다. 클라이언트가 보내는 타일 배열이나 진영은 반영하지 않습니다.
- world_chunk의 (faction,x,y) 기본 키와 ON CONFLICT DO NOTHING으로 동시 최초 진입에서도 하나만 저장합니다. 이후에는 저장된 배열을 반환하므로 생성 규칙 변경으로 기존 지역이 달라지지 않습니다.
- 최초 발견자 닉네임과 생성 시각을 보관합니다. 재화·아이템·경험치 보상은 없습니다.
- 지역 출입구에서 인접 구역을 요청합니다. 매 프레임/한 칸 이동마다 서버 요청하지 않습니다.
- 첫 버전의 탐험 범위는 구역 좌표 -32~32로 제한합니다. 무한 월드가 아니며, 범위 밖으로는 이동하지 않습니다. 각 계정은 분당 최대 12개 새 구역만 생성할 수 있고 기존 구역 열람에는 이 생성 제한을 적용하지 않습니다.
- 타일 그래픽만 추후 이미지 자산으로 교체할 수 있습니다. 이동/충돌과 생성 데이터는 독립적입니다.

## 배포

0006_world_chunks.sql은 IF NOT EXISTS 방식입니다. 첫 로그인 탐험 요청에서 같은 테이블/인덱스를 자동 생성하므로 별도 운영 SQL이나 환경변수는 필요 없습니다. 기존 게시판·API 키 테이블은 바꾸지 않습니다.

## 검증 범위

생성기의 재현성·출입구 연결·충돌 범위를 도구 실행기의 순수 JS 검사로 확인했습니다. 실제 SQLite/Worker 통합 테스트를 tests/world.test.js에 추가했습니다. 현재 로컬 실행 환경과 브라우저 도구가 없어 신규 통합 테스트 및 실제 PC/모바일 조작은 실행하지 못했습니다.
